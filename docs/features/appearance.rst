Plot Style tab
==============

Global plot appearance settings live in the **Appearance** tab (palette icon).

Display options
---------------

- **Show grid** — draws dashed grid lines at tick positions.
- **X / Y log scale** — switches the respective axis to a logarithmic scale.
- **Reverse X / Y axis** — flips the axis direction so values run high → low.
- **Equal aspect ratio** — forces 1 data unit on X to equal 1 data unit on Y.
- **Custom axes W : H ratio** — controls the shape of the plot box
  independently of the figure window size (e.g. 4 : 3, 16 : 9).

Reference lines
---------------

Add horizontal or vertical marker lines at any position.  Each line has its
own color, linestyle, width, and opacity, controlled through the **⚙** gear
button.

Click **−** to remove the selected line; the checkboxes toggle visibility
without deleting.

Fill bands
----------

Shade a region between two positions on either the X or Y axis.  Useful for
tolerance bands, highlighted time ranges, or annotated regions.

Each band has its own color, opacity, and optional legend label.
