Export
======

Save the current plot from the **Export** tab (image icon).

Formats
-------

- **PNG** — raster image; resolution controlled by DPI.
- **PDF** — vector; DPI setting is ignored for the image content.
- **SVG** — vector; fully editable in Inkscape, Illustrator, etc.

The file extension is managed automatically when you change the format.

Settings
--------

- **Filename** — type a path directly or click **Browse…** to pick a location.
- **Resolution** — 72 – 600 dpi (raster formats only); defaults to a
  print-ready 300 dpi.
- **Transparent background** — omit the white figure background; the axes
  patch becomes transparent too.  Useful for overlaying on slides.

All export settings (format, DPI, transparency) persist across sessions.

Copy to clipboard
-----------------

Press **Ctrl+Shift+C** or click the clipboard button in the toolbar to copy
the current plot as a 300 dpi PNG to the system clipboard — ready to paste
into any document, email, or chat.
