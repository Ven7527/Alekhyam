Alekhyam documentation
======================

**Plot CSV data instantly — no notebook, no boilerplate.**

Alekhyam is a desktop application for visualising CSV files with
publication-ready matplotlib figures. Load one or more files, configure
series, tweak styles, and export — all without writing a line of Python.
